LoRA Fine-tune Studio: Zero to Mastery

An applied course in natural language processing, transformers, parameter-efficient fine-tuning, preference optimization, evaluation, and the implementation of this repository.

This handbook is designed for three readers at once:

  • a beginner who needs every important term explained;
  • an ML practitioner who wants to design and evaluate useful training runs; and
  • a maintainer who needs to understand how the application turns UI choices into durable artifacts.

The course is cumulative. Complete Modules 1-5 before running the labs if transformers and fine-tuning are new to you. Experienced readers can use the module objectives and checkpoints to skip familiar material.

Implementation labels

Implemented means the current application exposes and tests the behavior. Context only means the idea is taught because it helps you reason about LLMs, but the application does not implement it. When this handbook and the repository differ, the code and passing tests are authoritative.
